# Atrazo design

Approved UI mockups for Atrazo, the offline-first utang ledger.

- `screens/`: PNG renders of every screen (light theme, plus dark dashboard and ledger), the UI kit sheet and the brand sheet.
- `canvas/`: the design-canvas source. Each `*.dc.html` file is one screen, `atrazo.css` holds the shared tokens and components (light + dark), and `canvas.json` lays the boards out. These files need the canvas runtime to render, so open the live canvas to click through: https://claude.ai/artifact/5A7AJByKvTmhdL2ycMkbY6

The app's styles are built from `canvas/atrazo.css`: same colour tokens, component names and states.
